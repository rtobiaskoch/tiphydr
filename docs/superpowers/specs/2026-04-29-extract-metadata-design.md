# Design: `extract_metadata()`

**Date:** 2026-04-29  
**Status:** Approved  
**Package:** tiphydr

---

## Purpose

Parse delimited metadata embedded in FASTA sequence headers (e.g. GISAID-style
`hCoV-19/Wuhan/WH04/2020|EPI_ISL_406801|2020-01-05`) into a tidy tibble with
one row per sequence and one column per metadata field. The function is
deliberately narrow — it returns metadata only, leaving sequence handling to
`fasta_nest()` / `fasta_unnest()`.

---

## Signature

```r
extract_metadata(biostring, names, delim = "|")
```

| Argument    | Type              | Description |
|-------------|-------------------|-------------|
| `biostring` | `XStringSet`      | A Biostrings object (typically `DNAStringSet`) whose `names()` hold delimited metadata. Named to match other tiphydr functions. |
| `names`     | `character` vector | Column names for the output tibble. Length controls how many fields are extracted. The first element is conventionally the sequence ID / strain name. |
| `delim`     | `character(1)`    | Field delimiter. Default `"|"` for GISAID. Treated as a fixed string, not a regex. |

**Returns:** a `tibble` with `length(names)` columns and one row per sequence in `biostring`.

---

## Behaviour

### Happy path

1. Extract `base::names(biostring)` — the raw header strings.
2. Split with `stringr::str_split_fixed(headers, pattern = stringr::fixed(delim), n = length(names))`.  
   This returns a `character` matrix: rows = sequences, columns = fields.  
   Extra fields beyond `length(names)` are silently dropped by `str_split_fixed`.
3. Convert empty strings `""` (produced when a header has fewer fields than `length(names)`) to `NA_character_`.
4. Coerce to tibble with `tibble::as_tibble(.name_repair = "minimal")`, setting `colnames = names`.
5. Return the tibble.

### Short-header handling

If any sequence header produces fewer fields than `length(names)`, `str_split_fixed`
pads the missing positions with `""`. After converting those to `NA`, emit a single
`warning()` that lists the affected sequence names so the user knows which records
are incomplete.

### Input validation (fail fast, clear messages)

| Check | Error message |
|-------|---------------|
| `biostring` is not an `XStringSet` | `"biostring must be an XStringSet (e.g. DNAStringSet)"` |
| `names` is not a non-empty character vector | `"names must be a non-empty character vector"` |
| `names` contains duplicates | `"names contains duplicate column names: <list>"` |
| `delim` is not a length-1 non-empty string | `"delim must be a single non-empty string"` |

## Example

```r
library(Biostrings)
library(tiphydr)

seqs <- DNAStringSet(c(
  "hCoV-19/Wuhan/WH04/2020|EPI_ISL_406801|2020-01-05" = "ATCG",
  "hCoV-19/USA/CA-CDPH/2021|EPI_ISL_999999|2021-06-15" = "GCTA"
))

extract_metadata(
  biostring = seqs,
  names     = c("strain", "accession", "date"),
  delim     = "|"
)
# # A tibble: 2 × 3
#   strain                       accession      date
#   <chr>                        <chr>          <chr>
# 1 hCoV-19/Wuhan/WH04/2020      EPI_ISL_406801 2020-01-05
# 2 hCoV-19/USA/CA-CDPH/2021     EPI_ISL_999999 2021-06-15
```

## Test cases

| Scenario | Expected outcome |
|----------|-----------------|
| Well-formed headers, exact field count | Correct tibble, no warning |
| Header has more fields than `names` | Extra fields silently dropped, no warning |
| Header has fewer fields than `names` | Missing fields → `NA`, warning listing affected names |
| All headers short | All-`NA` columns for missing fields + warning |
| `biostring` not an XStringSet | `stop()` with clear message |
| `names` has duplicates | `stop()` with duplicate list |
| Single-sequence input | One-row tibble |
| Custom delimiter (e.g. `/`) | Splits on correct character |

---

## Out of scope

- Type coercion of fields (dates, integers) — caller responsibility
- Returning sequences alongside metadata — use `fasta_nest()` for that
- Regex delimiters — `delim` is always treated as a fixed string
